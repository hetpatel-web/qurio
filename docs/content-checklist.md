# Content Checklist

## Frontmatter Checklist

- `title` is present and clear.
- `description` is present and explains the entry in one sentence.
- `date` uses `YYYY-MM-DD`.
- `status` is one of `idea`, `active`, `complete`, `paused`, `archived`.
- `tags` is a non-empty list of useful tags.

## Structure Checklist By Content Type

Experiments:

- `Question`
- `Hypothesis`
- `Setup`
- `Steps`
- `Result`
- `What Worked`
- `What Failed`
- `Lessons Learned`
- `Next Experiment`

Notes:

- `Purpose`
- `Key Idea`
- `Explanation`
- `Practical Use`
- `Related Experiments`
- `Takeaways`

Journal:

- `What I Worked On`
- `What I Learned`
- `What Changed`
- `Wins`
- `Challenges`
- `Next Focus`

Now:

- `Current Focus`
- `What I Am Learning`
- `What I Am Building`
- `What Is Paused`
- `Next Step`

## Publishing Checklist

- Entry is in the correct collection.
- Frontmatter passes validation.
- Links and references point to real entries when possible.
- `npm run typecheck` passes.
- `npm run build` passes.

## Quality Checklist

- Writing is calm, practical, honest, and reading-first.
- Claims are grounded in actual work, not hype.
- Friction and failure are documented where relevant.
- Next steps are concrete enough to guide future work.
